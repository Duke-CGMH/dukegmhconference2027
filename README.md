# 2027 Duke Global Mental Health Conference

A responsive static recreation of the public-facing 2027 Duke Global Mental Health Conference site. It uses plain HTML, CSS, and a small JavaScript file for the mobile navigation; there is no build step.

## Pages

- `index.html` — conference overview
- `registration-abstract-submission.html` — abstract submission information and guidelines
- `sponsors.html` — conference sponsors and sponsorship information
- `connect.html` — contact details and CGMH social links
- `past-conferences.html` — summary and link to the 2025 conference

## Add the original site images

Image placeholders are included so the site layout is ready while you gather image files. See `assets/images/README.md` for the requested image names and the one-line HTML replacement pattern. The site does not ship with the original source images yet.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Publish with GitHub Pages

Push the contents of this folder to a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select the branch and `/ (root)` folder, and save. The pages link to each other using relative paths, so they work from a project subpath.

The registration and abstract buttons link to the source site's Duke Qualtrics forms.
